# Third Party Software
This document contains a list of third-party libraries that ALPS for Native uses. ALPS for Native is
built from source as part of this module. Its sources are included as a git submodule in
`repos/dlb_alps_native` (see [ALPS Native](https://github.com/DolbyLaboratories/alps-native)).

Libraries compiled into the AlpsCore native library:
* [dlb_mp4demux](https://github.com/DolbyLaboratories/dlb_mp4demux). BSD 3-Clause License.

Libraries used only for ALPS for Native unit tests (not part of AlpsCore):
* [cmocka](https://cmocka.org). Apache 2.0 License.
