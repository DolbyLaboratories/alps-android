AlpsHlsHttpDataSource

@UnstableApi
internal class AlpsHlsHttpDataSource(alpsHlsManager: AlpsManagerHls, defaultHttpDataSourceFactory: HttpDataSource.Factory) : DataSource

A DataSource used for HLS media segments that resolves whether ALPS processing should be applied on the first open call, then delegates to either AlpsProcessing (AC-4 stream) or a plain HttpDataSource (non-AC-4 stream) for all subsequent calls.

alpsHlsManager

Source of the rendition-URL→Alps map and playlist tracker.
