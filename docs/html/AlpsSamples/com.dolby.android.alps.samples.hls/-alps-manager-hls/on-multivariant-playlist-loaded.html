onMultivariantPlaylistLoaded

internal fun onMultivariantPlaylistLoaded(streamUri: Uri, playlist: HlsMultivariantPlaylist)

Called by DelegatingHlsPlaylistTracker each time a multivariant playlist is loaded — once for the content stream and once for each interstitial.

The streamUri (the initialPlaylistUri from the tracker's HlsPlaylistTracker.start call) uniquely identifies the HLS stream. AC-4 renditions are registered under this URI in streamAlpsMaps.

Duplicate rendition URLs (from a live playlist refresh) are naturally prevented by checking streamAlpsMaps membership before registration.
